## Open decisions (owner has not answered)

1. **Version.** Suggested 4.1.0 for all three packages. Strict semver would say 5.0.0
   because of the behaviour changes.
2. **Commit.** Not done; the owner must ask. No `Co-Authored-By` trailer.
3. **Publish.** Needs explicit go-ahead after the version is set.
4. **Undefined global tokens.** Ten tokens are read by ~90 style rules but never defined,
   so those styles do nothing: `--ml-color-text-tertiary`, `--ml-color-error`,
   `--ml-color-error-subtle`, `--ml-color-surface-hover`, `--ml-color-surface-secondary`,
   `--ml-color-surface-tertiary`, `--ml-color-bg-secondary`, `--ml-color-text-disabled`,
   `--ml-transition-normal`, `--ml-font-regular`. Fixing means defining them as aliases
   (e.g. error → danger), which visibly changes dropdown, sidebar, slider, dialog, list,
   app-shell and calendar. Not started.
5. **Legacy font files.** 15 tracked `.svg`/`.ttf`/`.woff` files (~20 MB) in
   `packages/melodic-components/assets/fonts/phosphor/` are no longer published or
   referenced. Deleting them is the owner's call.
6. **`DialogService.open()` string overload.** Inline dialogs need `'name' as UniqueID`
   today. Not changed.

## Release steps once the version is chosen

1. Bump `package.json` (root), `packages/melodic-components/package.json`,
   `packages/cli/package.json`; update the CLI templates' `@melodicdev/*` ranges if needed.
2. Rename `## Unreleased` in `CHANGELOG.md`; put the number in the `MIGRATION.md`
   "Unreleased" heading and the header lines of `USING_MELODIC.md`,
   `MELODIC_FRAMEWORK.md`, `MELODIC_COMPONENTS.md`, and the `CLAUDE.md` package table.
3. `npm install --package-lock-only --ignore-scripts`.
4. `npm run build:lib && npm run build:bundle && npm run build:components`, then
   `npm run benchmark:update`.
5. `npm run test:all`, `npm run smoke:apps`, `npm run size`.
6. Commit, `git tag vX.Y.Z`, push branch and tag explicitly.
7. `npm publish` (core), `npm publish --workspace @melodicdev/components`,
   `npm publish --workspace @melodicdev/cli`.
8. Loop `npm run smoke:cdn -- X.Y.Z` until PASS (registry and esm.sh lag a few minutes).
