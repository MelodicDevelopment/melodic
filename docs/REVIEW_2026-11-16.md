## Follow-up on 2026-11-23

- **Undefined tokens:** the ten global tokens are now defined as aliases of existing ones
  (`error` → `danger`, `surface-hover` → `surface-raised`, `text-tertiary` → `text-muted`,
  …). Several consumer projects already define these names in their themes and keep their
  values. `tests/theme/undefined-tokens.test.ts` fails if a component reads a token that
  is defined nowhere.
- **Slider fill (4.0.1 regression):** that test found `ml-slider` building its fill width
  from `var(--ml-slider-thumb-size)` with no fallback, so the fill had no width once the
  `:host` token blocks were removed. Fixed.
- **`DialogService.open()` / `close()`** take a plain string id.
- **Legacy fonts:** 14 `.ttf` / `.woff` / `.svg` files removed (about 17 MB).
  `Phosphor.svg` stays; `npm run generate:icon-map` reads it.
- **Docs:** audited against source by area (core, components, CLI) and corrected: 59
  findings, mostly in the per-topic guides and `packages/melodic-components/docs/`.
- **CLI:** `melodic add` with no subcommand names all four; tests added for hyphen-run
  collapsing. `IToastRef`, `IDialogConfig` and `TableRowKey` are now exported.

## Rule followed: nothing public removed

Unused public API is marked `@deprecated` and still works: `RouteContextEvent`,
`ROUTE_CONTEXT_EVENT`, `IRouteContextChangeEvent`, `repeatRaw`,
`ITemplatePart.renderedContainers`. About 25 local projects consume Melodic, so keep it
that way.

## Decisions

1. **Version:** 4.1.0 for all three packages (owner, 2026-11-23).
2. **Undefined tokens, legacy fonts, `DialogService` string ids:** done, see above.
3. **Still open:** `add config` / `add testing --path` are not confined to the project the
   way `generate --path` and `add app|lib --dir` are. The docs now say so; whether to
   confine them is a behaviour decision.
4. **Still open:** the slider track uses `--ml-color-surface-hover` (gray-50 on white), which
   is faint next to the progress track (`surface-sunken`). Changing the default would move
   the slider off a token that consumer themes (mhsst, at least) already set.
